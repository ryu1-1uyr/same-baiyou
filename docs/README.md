# 調査ノート

ゲーム設計・UX に関する調査のストック。
Web 開発の知見はあるがゲーム開発の知見が薄い、という前提で集めている。

各ノートは三部構成。

1. **調べたこと** — 出典から拾った内容
2. **この企画（サメ培養プロジェクト）にどう当てはまるか** — 判断に落とした結果
3. **余談・細部** — 式の導出、用語の出どころ、実装の落とし穴、反例

1 と 2 が本体で、読み物として終わらせず判断に使えるようにするためのもの。
3 は要約の過程で落ちる周辺の情報を後から書き足したもので、
**読み飛ばしても 1 と 2 の結論は変わらない**。

## 読む順のおすすめ

1. **05（報酬と動機づけ）** — なぜ人が遊び続けるのかの土台。ここを外すと他が空回りする
2. **01（インクリメンタル）** — このジャンル固有の数学
3. **03（手触り）** — 実装に直結し、費用対効果が最も高い
4. **02（UI / UX）** — 情報設計。作り込むほど効いてくる
5. **04（事例）** — 全体を俯瞰し直すのに使う
