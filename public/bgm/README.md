# BGM の差し替え手順

ここに決められた名前で音源を置くと、コードで合成している BGM を自動的に差し替える。
**コードの変更は不要。**

ファイルが無ければこれまで通り合成のドローンが鳴るので、いつ置いてもよい。

## 手順

1. 下の一覧から作りたい場面を選ぶ
2. **mp3 か ogg** で書き出す
3. 一覧のパスと同じ場所・同じ名前で保存する
4. ブラウザをリロードする

以上。ビルドもコード変更も要らない。

## 一覧

| ファイル                  | 鳴る場面                                   |
| ------------------------- | ------------------------------------------ |
| `public/bgm/culture.mp3`  | 培養フェーズ（開始 60 秒の安全時間）       |
| `public/bgm/invasion.mp3` | 侵略フェーズ（深度 1〜10 の深海）          |
| `public/bgm/sky.mp3`      | 深度 11 以降（深度が反転して空へ抜けた後） |

**1 本だけ置いてもよい。** 見つからない場面は、置かれている別のトラックで代用する
（例: `culture.mp3` だけ置けば全編でそれが鳴る）。
1 本も無ければ合成のドローンに戻る。

場面が切り替わるときは 1.2 秒かけてクロスフェードする。

## 音源の仕様

- **mp3 か ogg**。同じ名前で両方あれば mp3 が使われる
- **全体がそのままループする。** イントロを付けたい場合も、
  ループさせたい範囲だけを書き出すこと（ループ点の指定は用意していない）
- 音量は画面右下の BGM スライダーで調整されるので、**書き出しの時点で音割れしない程度に整えておく**
- ステレオでよい

## 合成の BGM について

音源を置かないあいだは `src/audio/bgm.ts` が波形を合成して鳴らす。
深度に応じて基音とローパスが動き、深度 11 で音がこもりから開ける。
侵略フェーズでは脈動が加わり、制限時間が減るほど速くなる。

**音源を置いた場合、この加工は一切かからない。** 曲をそのまま鳴らす。

## リポジトリに置くかどうか

`public/` に置いたものはそのまま配信物に入る。
音源は数 MB になりやすいので、リポジトリが重くなるのが嫌なら
Git の管理から外して配信時にだけ置く方法もある（その場合は `.gitignore` に足す）。
